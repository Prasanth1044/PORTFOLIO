# Portfolio Website

This is a portfolio website built using React.js and Vite. It showcases various projects and provides information about the portfolio owner.

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd portfolio-vite-react
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the development server:**
   ```
   npm run dev
   ```

4. **Open your browser and navigate to:**
   ```
   http://localhost:3000
   ```

## Project Structure

- `index.html`: Main HTML file serving as the entry point for the application.
- `package.json`: Configuration file for npm, listing dependencies and scripts.
- `vite.config.js`: Configuration settings for Vite.
- `.gitignore`: Specifies files and directories to be ignored by Git.
- `jsconfig.json`: Configuration for JavaScript projects.

### Source Files

- `src/main.jsx`: Entry point for the React application.
- `src/App.jsx`: Main App component that includes routing and layout.
- `src/assets`: Directory for static files (images, fonts, etc.).
- `src/components`: Contains reusable components like Header, Footer, Nav, and ProjectCard.
- `src/pages`: Contains page components like Home, About, Projects, and Contact.
- `src/styles/main.css`: Main CSS styles for the application.
- `src/data/projects.js`: Exports an array of project objects.
- `src/utils/index.js`: Utility functions for the application.
